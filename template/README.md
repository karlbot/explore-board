# My Project explorations

The board for design explorations of My Project, each on its own branch. The page is
https://gallery-my-project.example.workers.dev.

**If you've been pointed here to post an exploration:** run `npm install`, then
`npm run instructions`, and follow what it prints. The same text is on the page, at
`/instructions.md`. What's below is particular to this project and wins where the two differ.

This branch shares no history with `main` and holds no app code. Never merge it into anything, or
anything into it.
